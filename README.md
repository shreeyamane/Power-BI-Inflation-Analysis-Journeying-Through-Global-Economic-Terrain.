## 📌 Project Overview

Inflation is one of the most important indicators of economic stability. It influences purchasing power, living standards, business decisions, and the overall economic health of a country.

This project explores global inflation patterns across **196 countries between 1980 and 2016**, using Microsoft Power BI to transform historical economic data into meaningful visual insights.

The dashboard provides an interactive way to understand how inflation has evolved across countries, identify economies experiencing extreme inflation, and compare inflation rates across different geographical regions.

The goal was not just to visualize numbers but to make complex economic patterns easier to understand through interactive data storytelling.

---

## 🎯 Project Objectives

* Analyze global inflation trends over multiple decades.
* Compare inflation rates across 196 countries.
* Identify countries experiencing the highest inflation.
* Examine average and maximum inflation rates.
* Understand variations in inflation across different economies.
* Build an interactive dashboard for exploring historical economic patterns.

---

## 📊 Dashboard Highlights

The dashboard focuses on the following analytical dimensions:

| Analysis                    | Description                                                                  |
| --------------------------- | ---------------------------------------------------------------------------- |
| Average Inflation           | Understand the average inflation rate across the dataset.                    |
| Maximum Inflation           | Identify the highest recorded inflation rates.                               |
| Global Trends               | Explore how inflation has changed between 1980 and 2016.                     |
| Country Comparison          | Compare inflation patterns across individual countries.                      |
| Top Inflation-hit Countries | Identify countries with exceptionally high inflation.                        |
| Economic Insights           | Understand historical inflation patterns through interactive visualizations. |

### 🔍 Key Findings

The analysis highlights several interesting observations:

* Venezuela, Congo, and Nicaragua emerged among the top three inflation-hit countries in the analysis.
* Inflation rates vary significantly across countries and economic environments.
* Historical inflation patterns reveal considerable differences in economic stability across nations.
* Country-level comparisons help identify economies that experienced exceptionally high inflation.

## 🔄 Project Workflow

The project followed a structured data analytics workflow:

**1. Data Collection**

Gathering historical inflation data covering multiple countries and years.

**2. Data Cleaning & Transformation**

Preparing the dataset, handling inconsistencies, and transforming the data into an analysis-ready format.

**3. Data Analysis**

Exploring inflation patterns, calculating key metrics, and comparing country-level performance.

**4. Dashboard Development**

Creating interactive visualizations and analytical components using Microsoft Power BI.

**5. Insights & Interpretation**

Identifying inflation hotspots, comparing economic patterns, and translating the analysis into meaningful insights.

## 🚀 How to Explore the Project


2. Navigate to the downloaded project folder.
