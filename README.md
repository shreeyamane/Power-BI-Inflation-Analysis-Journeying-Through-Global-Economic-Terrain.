## 📌 Project Overview

Inflation plays a crucial role in shaping the economic stability of nations. It directly influences purchasing power, living standards, business decisions, and the overall financial health of an economy.

This project, **Inflation Analysis: Journeying Through Global Economic Terrain**, explores historical inflation trends across **196 countries from 1980 to 2016** using Microsoft Power BI.

The project transforms historical economic data into interactive visualizations, enabling users to explore inflation patterns, compare countries, identify high-inflation economies, and understand the broader economic landscape.

Beyond dashboard development, the project follows a structured development lifecycle, covering ideation, requirement analysis, solution design, implementation, performance testing, and final documentation.

---

## 🎯 Project Objectives

* Analyze historical inflation trends across 196 countries.
* Identify countries experiencing exceptionally high inflation.
* Compare inflation patterns across different economies.
* Explore changes in inflation over multiple decades.
* Transform raw economic data into meaningful visual insights.
* Develop an interactive Power BI dashboard for economic exploration.

## 🔄 Project Development Lifecycle

The project was organized into six major phases to maintain a structured development approach.

### 01. Ideation Phase

Identifying the problem, understanding user perspectives, and evaluating the initial project idea.

**Deliverables:**

* Empathy Map Canvas
* Idea Prioritization
* Problem Statement

### 02. Requirement Analysis

Defining user requirements, understanding the data flow, and identifying the technical requirements of the solution.

**Deliverables:**

* Customer Journey Map
* Data Flow Diagrams and User Stories
* Solution Requirements
* Technology Stack

### 03. Project Design Phase

Developing the proposed solution and defining the overall system architecture.

**Deliverables:**

* Problem-Solution Fit
* Proposed Solution
* Solution Architecture

### 04. Project Executable Files

The core implementation phase, containing the dataset, Power BI dashboard, and supporting project outputs.

**Deliverables:**

* Global Inflation Dataset
* Power BI Dashboard (.pbix)
* Dashboard Visualization
* Project Report Visualization

### 05. Performance Testing

Evaluating the implemented solution through performance testing and validation.

**Deliverables:**

* Model Performance Test
* Model Performance Test II
* Power BI Testing Documentation

### 06. Documentation & Demo

Consolidating the project outcomes and presenting the completed solution.

**Deliverables:**

* Final Project Report
* Video Demonstration
